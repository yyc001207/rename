# 剧集文件批量重命名工具 · 使用手册

本工具用于把剧集文件夹中的视频与字幕文件，批量统一为 `S01E01`、`S02E05` 这样的规范命名，并支持**分季存储**。所有操作先预览、后执行，数据全程在本机处理，不联网、不上传。

主要能力一览：

| 能力 | 说明 |
| --- | --- |
| 目录结构识别 | 自动识别「剧集文件夹直接放文件」和「剧集文件夹 + 季文件夹」两种结构 |
| 集数自动识别 | 支持 `EP01`、`E01`、`第01集`、`[01]`、`S01E05` 等常见命名 |
| 从头重新编号 | 一键按文件名排序、从第 1 集开始重新编号 |
| 按集数拆分季 | 把单季打包的整部剧集按指定集数拆分为多季并移动到季文件夹 |
| 预览与手工微调 | 执行前逐文件预览，目标名称可直接修改 |
| 冲突处理 | 同名冲突可选跳过 / 自动编号 / 覆盖 |
| 操作日志 | 全程记录，页面可查看、可导出文件 |

---

## 一、安装与启动

### 1. 环境要求

- Node.js 18 或更高版本。安装地址：<https://nodejs.org>（选择 LTS 版本即可）
- 系统要求：Windows 全功能支持；macOS / Linux 除「浏览选择…」文件夹选择器外功能一致（手动输入路径即可）

### 2. 启动工具

**方式一（推荐，Windows）**：双击 `start.bat`。

**方式二（命令行）**：在工具目录打开终端，执行：

```bash
node server.mjs              # 启动并自动打开浏览器 http://127.0.0.1:3710
node server.mjs 3720         # 端口被占用时换一个端口
node server.mjs --no-open    # 只启动服务，不自动打开浏览器
```

看到「剧集文件批量重命名工具已启动」并自动打开浏览器，即启动成功。

### 3. 停止工具

在运行 `start.bat` / `node server.mjs` 的窗口中按 `Ctrl + C`，或直接关闭该窗口。

### 4. 试用演示数据（可选）

首次使用可先生成一份演示文件夹：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/create-demo.ps1
```

生成后，在界面中输入 `demo` 文件夹的完整路径（例如 `C:\Users\你的用户名\Desktop\code\rename\demo`）并扫描，即可体验全部功能。

## 二、快速上手（5 分钟）

1. **选择文件夹**：在「1 选择文件夹」中输入剧集文件夹路径（或点「浏览选择…」），点击「扫描」。
2. **核对预览**：在「2 预览与确认」中检查每个文件的「原文件名 → 新文件名」；有疑问的文件可取消勾选或直接修改新名称。
3. **执行**：点击「3 执行重命名」中的「确认重命名」。执行过程中显示进度条，结束后给出「成功 / 跳过 / 失败」数量与失败原因，并自动重新扫描刷新预览。
4. **查看日志**：页面底部「操作日志」记录全部操作，可点「导出日志」下载保存。

> 演示文件夹中的「老友记」是一级结构，「权力的游戏」是二级结构，「单季待拆分」可体验按集数分季（输入 `2,3`）。

## 三、界面说明

### 1. 选择文件夹

- **路径输入框**：直接输入本机文件夹的完整路径，回车或点「扫描」。
- **浏览选择…**：通过 PowerShell 弹出系统文件夹选择器（Windows）。选择后点「扫描」。
- **扫描结果摘要**：显示扫描到的剧集文件夹、季文件夹、媒体文件数量，以及无法识别集数、名称冲突、特殊集数(.5) 的数量统计。

### 2. 预览与确认

预览按「剧集文件夹 → 季」分组，每行展示：勾选框、原文件名、箭头、新文件名、状态徽标。

**徽标图例**：

| 徽标 | 含义 |
| --- | --- |
| 🔵 蓝色 | 识别出的集数（EP05）、自动编号、手动修改过（已修改） |
| 🟠 橙色 | 冲突警告：目标名称重复 / 目标名称已存在 / 与另一文件当前名称冲突 |
| 🔴 红色 | 无法识别集数、特殊集数(.5)、名称非法（空 / 非法字符 / 系统保留名） |
| ⚪ 灰色 | 已是目标名称（无需改动）、仅大小写调整 |
| 🟣 紫色 | 二级结构季文件夹、分季归属（分季 → SXXEYY · 移入 …） |

**选项说明**：

| 选项 | 作用 |
| --- | --- |
| 同名冲突处理 | 跳过（默认）/ 自动编号 / 覆盖，详见「七、同名冲突处理」 |
| 保留字幕语言标记 | 默认勾选。`xxx.chs.srt` → `S01E01.chs.srt`，防止多语言字幕互相覆盖 |
| 自动编号 | 勾选后，无法识别集数的文件按文件名排序，在已识别最大集数之后依次编号 |
| 是否从头开始 | 每个季分组各一个。勾选后该分组按文件名排序、从第 1 集重新编号（季数不变） |
| 按集数拆分季 | 仅一级结构显示。按指定集数把单季拆分为多季，详见「六、3 按集数拆分季」 |

- **勾选控制**：勾选/取消单个文件、每季标题栏「全选」、底部「全选 / 全不选」。
- **新文件名可直接编辑**：点击新文件名即可修改，重复、冲突、非法字符会实时标出。

### 3. 执行重命名

- **确认重命名**：按预览内容执行。已修改目标名的文件按修改后的名称执行。
- **取消 / 中止**：执行前点「取消」清空当前结果；执行中点「中止」停止剩余文件（已完成的不会回滚）。
- **进度条**：显示「正在重命名 X / N」与最近处理的文件名。
- **结果摘要**：成功 / 跳过 / 失败数量；失败文件列出具体原因；跳过文件可展开明细。

### 4. 操作日志

- 页面底部实时显示；点击「导出日志」下载 `.txt` 文件。
- 同时自动持久化到工具目录 `logs/rename.log`，可用于事后核对或手工恢复文件名。

## 四、目录结构识别

| 结构 | 判定方式 | 命名结果 |
| --- | --- | --- |
| 一级结构 | 剧集文件夹下**直接**包含视频/字幕文件 | 视为第一季 → `S01E01.mp4` |
| 二级结构 | 剧集文件夹下包含季文件夹 | 每季独立编号 → `S02E05.mp4` |

- 季文件夹命名支持：`S01`、`s1`、`Season 1`、`Season 02.1080p`、`第1季`、纯数字 `01`。
- 如果所选路径**本身就是**一个剧集文件夹（直接包含媒体文件或季文件夹），工具会自动按一级/二级结构处理。
- 剧集文件夹下同时存在季文件夹和散落媒体文件时，按二级结构处理，散落文件会被忽略并提示。
- 无法识别季数的子文件夹（如 `Specials`、`Behind the Scenes`）会被忽略并提示，其中文件不会被重命名。

---

## 五、集数识别规则

从文件名（不含扩展名）按优先级依次匹配，不区分大小写：

| 格式示例 | 识别结果 |
| --- | --- |
| `S01E05` / `s1e2` / `S01EP03` | 05 / 02 / 03 |
| `Episode 12` | 12 |
| `EP01` | 01 |
| `E01` | 01 |
| `第01集` / `第05话` | 01 / 05 |
| `[01]` / `(01)` | 01 |
| `01` / `101`（兜底：独立的 1~3 位数字，支持 100 集以上） | 01 / 101 |

- 识别前会先剔除 `4K`/`2K`/`8K`、`HDR10`、`x265`、`10bit`、`5.1` 声道、`4K_EA` 等画质/编码/音轨标记，其中的数字不会被误判为集数（如 `4K_EA` 不会被识别为第 4 集）；同时避开 `1080p`、`720p`、年份等干扰数字。
- **无法识别集数**的文件显示红色徽标并默认不勾选；可开启「自动编号」选项让其按排序依次编号。
- 集数统一为两位（不足补零），如第 5 集 → `E05`、第 101 集 → `E101`。

## 六、三种编号方式

### 1. 按文件名提取（默认）

直接使用「五、集数识别规则」从原文件名中提取的集数，保持原编号不变。

### 2. 是否从头开始（逐季重新编号）

在季分组标题栏勾选「是否从头开始」：

- **不勾选**：按文件名提取集数（默认行为）。
- **勾选**：按文件名自然排序，从第 1 集开始依次重新编号。
- 视频与同名字幕（如 `S01E07.mp4` 与 `S01E07.chs.srt`）**共用同一编号**，不会错位。
- **季数不变**：`Season 2` 仍生成 `S02EXX`。
- 勾选状态按文件夹记忆，切换其他选项或重新扫描后不会丢失。

### 3. 按集数拆分季（单季 → 多季分季存储）

用于把资源方按单季打包的整部剧集，按指定集数重新组织为多季。仅一级结构的分组显示「按集数拆分季」面板。

**操作步骤**：

1. 在面板中输入各季集数，用逗号分隔，例如：

   ```
   48, 48, 54, 25, 51, 39, 12, 51
   ```

   （即第一季 48 集、第二季 48 集、……、第八季 51 集，共 328 集）

2. 选择季文件夹命名方式（`Season N` / `S01` / `第N季`），勾选「移动到季文件夹」，点击「应用拆分」。
3. 预览立即刷新：蓝色分栏线标出各季边界（如「── 第 3 季 · 54 集 ──」），每行紫色徽标显示「分季 → S03E12 · 移入 Season 3」。
4. 核对无误后「确认重命名」：文件被重命名为 `SXXEYY` 并**移动**到自动创建的季文件夹中，完成分季存储。

**校验与保障**：

- 输入的集数之和必须等于文件（槽位）总数，否则拒绝应用并提示差值。
- 视频与同名字幕配对占用同一槽位，字幕会跟随视频进入同一季、同一集号。
- 移动目标文件夹必须位于扫描目录内；季文件夹自动创建；目标目录内的同名冲突按所选冲突模式处理。
- 不勾选「移动到季文件夹」时，只重命名、不移动。
- 想撤销拆分，点「清除拆分」即可恢复为默认命名。

## 七、同名冲突处理

当目标名称与现有文件重名时，按预览区所选模式处理：

| 模式 | 行为 |
| --- | --- |
| 跳过（默认，推荐） | 保留目标文件，源文件不改名，记录跳过原因 |
| 自动编号 | 生成 `S01E01 (2).mp4` 形式的唯一名称 |
| 覆盖 | 删除目标文件后重命名（**有数据丢失风险，执行前需二次确认**） |

说明：

- 已符合目标名称的文件（如已存在的 `S01E01.mp4`）显示灰色徽标并默认不勾选。
- 仅大小写不同的文件（`s01e01.mp4` → `S01E01.mp4`）通过两步重命名安全处理。
- 分季移动时，冲突按**目标文件夹**内实际情况判定。

## 八、字幕语言标记保留

默认开启。字幕文件名末尾的常见语言标记会被保留：

- `Friends.S01E07.chs.srt` → `S01E07.chs.srt`
- `S01E05.chs&eng.srt` → `S01E05.chs&eng.srt`

可防止简繁、中英等多语言字幕互相覆盖。如需统一去掉语言标记，取消勾选「保留字幕语言标记」即可。

---

## 九、.5 特殊集数处理

若文件名包含 `.5` 格式的集数（如 `5.5`、`E05.5`、`S01E05.5`、`第12.5集`），工具会：

- 在该文件行显示红色徽标「特殊集数 .5：需手动输入目标编号」；
- 在所属季分组顶部显示红色警告；
- 在扫描摘要中统计数量；
- **默认取消勾选**，避免被自动编号覆盖。

**处理办法**：在预览中手动把该文件的目标名改为正确的特殊集数（如 `S01E05.5.mkv`），再勾选执行。若此类文件本就无需处理，保持不勾选即可。

---

## 十、自定义目标名称（手动修改）

预览中「新文件名」一列可直接编辑：

- **实时检查**：与其他文件的目标重复、与现有文件冲突 → 橙色徽标；空名称、路径分隔符（`\` `/`）、Windows 非法字符（`< > : " | ? *`）、系统保留名（`CON`、`PRN`、`NUL`、`COM1` 等）→ 红色徽标，且不会提交执行。
- 蓝色「已修改」徽标表示该名称已被手动修改；点「重新扫描」会恢复为自动计算值。
- 执行前服务端会**再次校验**每个名称，保证重命名/移动始终发生在扫描目录内。

## 十一、支持的媒体格式

**视频**：`.mp4 .mkv .avi .mov .flv .wmv .ts .m2ts .mts .webm .rmvb .rm .mpg .mpeg .m4v .3gp .ogm`

**字幕**：`.srt .ass .ssa .sub .smi .vtt .idx .sup .lrc`

其他文件（`.nfo`、`.jpg`、`.txt` 等）会被忽略并在预览中提示。

## 十二、典型场景示例

### 场景一：整理命名混乱的剧集文件夹

1. 扫描剧集文件夹；
2. 默认按文件名提取集数，核对预览中每行「原名 → 新名」；
3. 无法识别的文件：开启「自动编号」或手动填写集数；
4. 「确认重命名」。

### 场景二：希望每季从第 1 集重新编号

1. 扫描后，在目标季分组标题栏勾选「是否从头开始」；
2. 核对重新编号结果（视频与字幕同号）；
3. 「确认重命名」。

### 场景三：单季 328 集拆分为 8 季存储

1. 扫描单季剧集文件夹；
2. 在「按集数拆分季」输入 `48, 48, 54, 25, 51, 39, 12, 51`；
3. 选择「Season N」命名，勾选「移动到季文件夹」，点「应用拆分」；
4. 核对 8 季边界分栏与每行归属；
5. 「确认重命名」→ 自动生成 `Season 1`~`Season 8` 文件夹，文件按 `S01E01`~`S08E51` 分季存储。

### 场景四：包含特殊集数（如 5.5）

1. 扫描后关注红色徽标文件（默认未勾选）；
2. 手动输入其目标名（如 `S01E05.5.mkv`）并勾选；
3. 其余文件正常勾选，统一执行。

## 十三、安全与数据保护

- **预览确认制**：所有重命名前必须先扫描并确认预览；服务端只允许处理扫描结果中的文件。
- **冲突默认跳过**；「覆盖」模式需二次确认。
- 服务仅监听 `127.0.0.1`，局域网内其他设备无法访问。
- 重命名/移动仅发生在扫描目录内，不跨设备复制；移动目标文件夹越界会被服务端拒绝。
- 全部操作写入日志（页面 + `logs/rename.log`），可据此手工回溯。
- **建议**：首次使用先在演示文件夹上试用；处理重要剧集前先备份。

## 十四、常见问题（FAQ）

**Q：端口被占用怎么办？**
A：换一个端口启动，例如 `node server.mjs 3720`。

**Q：点击「浏览选择…」没反应或失败？**
A：该功能通过 PowerShell 弹出系统文件夹选择器，对话框会自动置顶。若仍未见，检查是否被其他窗口遮挡；等待超过 2 分钟会超时并在界面显示原因。环境无图形界面时，直接手动输入路径即可（功能完全等价）。

**Q：某些文件重命名失败？**
A：查看结果摘要中的失败原因，常见为文件被播放器/下载软件占用（`EBUSY`/`EPERM`）、只读属性、权限不足。关闭占用程序后重试即可。

**Q：两个文件都想改成同名？**
A：先勾选其一执行，重新扫描后再处理另一个；或使用「自动编号」模式一次完成。

**Q：直接双击 index.html 打不开？**
A：必须通过 `node server.mjs`（或 `start.bat`）启动后访问 <http://127.0.0.1:3710>。

**Q：拆分季时提示「集数之和应为 N」？**
A：输入的集数总和必须等于文件（槽位）总数。若文件夹中字幕与视频同名，它们只占一个槽位，请按提示的槽位数填写。

**Q：如何恢复被重命名的文件？**
A：依据日志（页面导出或 `logs/rename.log`）中记录的原文件名，手工改回。
