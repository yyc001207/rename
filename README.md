# 剧集文件批量重命名工具

基于 JavaScript（Node.js + 原生 Web 界面）的本地批量重命名工具，将剧集文件夹中的视频与字幕统一重命名为 `S01E01` / `S02E05` 规范，支持一级/二级目录结构识别、预览确认、同名冲突处理与操作日志导出。**零外部依赖**，数据全程在本机处理。

## 为什么需要一个本地服务？

浏览器出于安全限制无法访问任意磁盘路径，而本工具需要「手动输入真实路径 + 实际执行重命名」，因此采用「本地 Node.js 服务 + Web 界面」的架构：界面在浏览器中操作，文件读写由本机服务完成，只监听 `127.0.0.1`，不对外开放。

## 环境要求

- Node.js 18 或更高版本（<https://nodejs.org>）
- Windows 支持「浏览选择…」图形化选择器（依赖 PowerShell，系统自带）；macOS / Linux 请手动输入路径

## 快速开始

```bash
# 方式一：双击 start.bat（Windows）
start.bat

# 方式二：命令行
node server.mjs          # 启动后自动打开浏览器 http://127.0.0.1:3710
node server.mjs 3720     # 指定端口
node server.mjs --no-open   # 不自动打开浏览器
```

首次使用可先创建演示文件体验：

```powershell
# Windows PowerShell 5.1（系统自带）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/create-demo.ps1
# 或 PowerShell 7+
pwsh -NoProfile -File scripts/create-demo.ps1
```

然后在界面中输入 `demo` 文件夹的完整路径并扫描。

## 使用流程

1. **选择文件夹**：手动输入路径，或点击「浏览选择…」弹出系统文件夹选择器，然后点击「扫描」。
2. **预览与确认**：按剧集 → 季 分组展示每个文件的 原文件名 → 新文件名；**新文件名可直接编辑**，重复、冲突或非法字符实时标出；可勾选/取消单个文件、整季全选。
3. **执行重命名**：点击「确认重命名」，显示实时进度条；完成后展示成功/跳过/失败数量及失败原因，并自动重新扫描刷新预览。
4. **日志**：操作日志实时显示在页面底部，可「导出日志」下载；同时持久化到 `logs/rename.log`。

## 结构识别规则

| 结构 | 判定方式 | 命名结果 |
| --- | --- | --- |
| 一级结构 | 剧集文件夹下**直接**包含视频/字幕文件 | 按第一季处理 → `S01E01.mp4` |
| 二级结构 | 剧集文件夹下包含季文件夹 | 每个季文件夹 → `S02E05.mp4` |

- 季文件夹命名支持：`S01`、`s1`、`Season 1`、`Season 02.1080p`、`第1季`、纯数字 `01`。
- 剧集文件夹下同时存在季文件夹和散落媒体文件时，按二级结构处理，散落文件被忽略并提示。
- 未识别季数的子文件夹（如 `Specials`、`Behind the Scenes`）会被忽略并给出警告，其中的文件不会被重命名。
- 所选路径本身就是一个剧集文件夹时，会自动按一级/二级结构处理。

## 集数识别规则

按优先级依次匹配（不区分大小写）：

| 格式示例 | 识别结果 |
| --- | --- |
| `S01E05` / `s1e2` / `S01EP03` | 05 / 02 / 03 |
| `Episode 12` | 12 |
| `EP01` | 01 |
| `E01` | 01 |
| `第01集` / `第05话` | 01 / 05 |
| `[01]` / `(01)` | 01 |
| `01`（兜底：独立的 1~2 位数字） | 01 |

- 无法识别集数的文件在预览中显示红色徽标，默认**不勾选**；可开启「自动编号」选项，按文件名排序在已识别最大集数之后依次编号。
- 兜底规则会主动避开 `1080p`、`720p`、年份等常见干扰数字。

## 同名冲突处理

预览中以橙色徽标提示三种冲突：目标名称重复、目标名称已存在、与另一文件当前名称冲突。执行时遇到同名目标，按所选模式处理：

| 模式 | 行为 |
| --- | --- |
| 跳过（默认） | 保留目标文件，源文件不改名，记录跳过原因 |
| 自动编号 | 生成 `S01E01 (2).mp4` 形式的唯一名称 |
| 覆盖 | 删除目标文件后重命名（**有数据丢失风险，需二次确认**） |

已符合目标名称的文件（如已存在的 `S01E01.mp4`）会显示灰色徽标并默认不勾选；仅大小写不同的文件（`s01e01.mp4` → `S01E01.mp4`）通过两步重命名安全处理。

## 自定义目标名称

预览中「新文件名」一列是可直接编辑的输入框，编辑时会实时进行重复与合法性检查：

- **实时重复检查**：与其他文件的目标名称重复、与同文件夹内现有文件名冲突，都会以橙色徽标实时标出；执行时仍按所选冲突模式（跳过 / 自动编号 / 覆盖）处理。
- **合法性检查**：空名称、路径分隔符（`\` `/`）、Windows 非法字符（`< > : " | ? *` 等）、系统保留名（`CON`、`PRN`、`NUL`、`COM1` 等）会显示红色徽标，且不会提交执行。
- 蓝色「已修改」徽标表示该名称已被手动修改；「重新扫描」会恢复为自动计算值。
- 服务端在真正执行前会**再次校验**每个目标名称（防止绕过前端），非法名称以失败原因返回，保证重命名始终发生在原文件夹内。

## 支持的文件类型

**视频**：`.mp4 .mkv .avi .mov .flv .wmv .ts .m2ts .mts .webm .rmvb .rm .mpg .mpeg .m4v .3gp .ogm`

**字幕**：`.srt .ass .ssa .sub .smi .vtt .idx .sup .lrc`

其他文件（`.nfo`、`.jpg`、`.txt` 等）会被忽略并在预览中提示。

## 字幕语言标记保留

默认开启。字幕文件名末尾的常见语言标记会被保留：`Friends.S01E07.chs.srt` → `S01E07.chs.srt`、`x.chs&eng.srt` → `S01E01.chs&eng.srt`。避免多语言字幕（简繁、中英）互相覆盖。可在预览中关闭该选项。

## 安全说明

- **预览确认制**：所有重命名前必须先扫描并确认预览，服务端只允许重命名扫描结果中出现的文件。
- 冲突默认「跳过」；「覆盖」模式需二次确认。
- 服务仅监听 `127.0.0.1`，局域网内其他设备无法访问。
- 重命名仅发生在原文件夹内，不移动、不复制、不删除源文件内容；失败会记录原因。
- 自定义目标名称需通过安全校验（无路径分隔符、Windows 非法字符、系统保留名），服务端执行前会再次校验。
- 全部操作写入日志（页面 + `logs/rename.log`），可据此手工回溯。
- 重要文件建议先备份；执行后如需恢复，请依据日志记录的原文件名手工改回。

## 常见问题

**端口被占用**：`node server.mjs 3720` 换一个端口（或设置环境变量 `PORT`）。

**点击「浏览选择…」没反应/失败**：该功能会通过 PowerShell 弹出系统文件夹选择器。对话框会自动置顶显示——若仍未见，请检查是否被其他窗口遮挡或任务栏是否有「Windows PowerShell」窗口；等待超过 2 分钟会超时并在界面显示失败原因。若环境无图形界面或 PowerShell 受限，直接**手动输入路径**即可（功能完全等价）。

**某些文件重命名失败**：查看结果摘要中的失败原因。常见为文件被播放器/下载软件占用（`EBUSY`/`EPERM`）、只读属性、权限不足。

**两个文件都想改成同名**：先勾选其一执行，重新扫描后再处理另一个，或使用「自动编号」模式一次完成。

**直接双击 index.html 打开**：不行，必须通过 `node server.mjs` 启动后访问 <http://127.0.0.1:3710>。

## 目录结构

```
rename/
├── server.mjs               # 本地服务（扫描 / 重命名 / 日志 API）
├── public/index.html        # Web 界面
├── start.bat                # Windows 一键启动
├── scripts/create-demo.ps1  # 演示文件生成脚本
├── test/episode.test.mjs    # 识别规则单元测试
├── test/http-test.mjs       # 端到端 HTTP 测试（自建夹具）
├── logs/rename.log          # 操作日志（运行时自动生成）
└── demo/                    # 演示文件夹（由 scripts/create-demo.ps1 生成）

运行全部测试：`npm test`（或 `node test/episode.test.mjs && node test/http-test.mjs`）
```
